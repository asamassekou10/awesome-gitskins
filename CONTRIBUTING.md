# Contributing

Thanks for wanting to share your profile! Adding it takes a couple of minutes.

## Add your profile

1. Make sure your GitHub profile README (or portfolio) was built with [GitSkins](https://www.gitskins.com) and looks finished: no broken images, no placeholder text.
2. Take a screenshot of the top of your profile README, about 800 px wide and up to 640 px tall, and save it as a JPG or PNG named after your username in lowercase, for example `assets/profiles/octocat.jpg`.
3. Add yourself to the section in `README.md` that fits your style best (Neon & cyber, Terminal & ASCII, Warm & bold, Light & minimal or Playful visuals), copying the format of the entries around it.
4. Open a pull request titled `Add @your-username`.

One profile per person, and please only submit your own.

## What we look for

The list is curated, so not every pull request will be merged. We favour profiles that are polished, show some personality, and tell visitors something real about the person and their work.

## Remove a profile

If you're listed and would rather not be, open an issue titled "Remove my profile" or a pull request that deletes your entry and screenshot. We'll remove it right away.
